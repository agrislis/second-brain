# Workflows

## English

### Session pack

Capture only state-changing information: decisions, confirmed facts, preferences, tasks, entities, open questions, and memory candidates. Label hypotheses explicitly and preserve the original source date.

### Dry-run ingest

Before changing canonical files, show:

- discovered sources;
- extracted facts;
- proposed create, update, and skip actions;
- content-hash and semantic duplicates;
- conflicts and unresolved questions;
- memory candidates.

### Apply changes

After confirmation, update existing topical notes where appropriate. Create a new file only for a distinct new topic. Update the operational state, maps of content, and index. Record a report and patch.

### Daily maintenance

Process current inbox inputs, run ingest, update exports, and surface conflicts and open loops. Do not attempt to reconstruct missed runs unless the user explicitly requests it.

### Memory digest

Create a compact summary of the current focus, active projects, recent decisions, and open questions. Add a manifest with canonical paths and content hashes. Do not include full notes or sensitive records.

### Historical imports

Preserve original dates and source identities. Historical material must not overwrite current state or decisions unless the user explicitly marks it as currently applicable.

## Русский

### Session pack

Сохраняйте только информацию, изменяющую состояние базы: решения, подтверждённые факты, предпочтения, задачи, сущности, открытые вопросы и memory candidates. Явно помечайте гипотезы и сохраняйте исходную дату источника.

### Dry-run ingest

До изменения canonical-файлов покажите:

- найденные источники;
- извлечённые факты;
- предлагаемые действия create, update и skip;
- дубли по content hash и смыслу;
- конфликты и нерешённые вопросы;
- memory candidates.

### Применение изменений

После подтверждения обновляйте существующие тематические заметки, где это уместно. Создавайте новый файл только для отдельной новой темы. Обновите оперативное состояние, карты знаний и индекс. Зафиксируйте отчёт и patch.

### Ежедневное обслуживание

Обрабатывайте текущие входы inbox, выполняйте ingest, обновляйте экспорты и выносите на первый план конфликты и открытые вопросы. Не восстанавливайте пропущенные запуски без явного запроса пользователя.

### Memory digest

Создавайте компактную сводку текущего фокуса, активных проектов, последних решений и открытых вопросов. Добавляйте манифест с canonical paths и content hashes. Не включайте полные заметки или чувствительные записи.

### Исторические импорты

Сохраняйте исходные даты и идентификаторы источников. Исторические материалы не должны перезаписывать текущее состояние или решения, если пользователь явно не отметил их как актуальные сейчас.
